Verify it yourself

Every check on this page runs in your browser, with the same rule code the repository's tests run (lib/trade.mjs, lib/countersign.mjs). It reads public records: Takar's receipts, the Telegraph node and Countersign's memos. Nothing here asks Takar's server for a verdict.

Re-decide every Trade Assurance round

Each evidence round stored the miners' answers, the port's record and the parties' documents. Here they are run through the rules again; the decision and payout must equal what was recorded, and acted on, on chain.

Recompute a Telegraph signal

A signal's hash is keccak256 of its payload as canonical JSON. Fetched straight from the Telegraph node and recomputed here: a match means the stored request and answer are exactly what the signal committed to. The node does not sign, so this shows integrity, not who produced the answer.

Check a Countersign memo

Countersign (another Season II team) signs shipment reports. The memo's digest is recomputed and its EIP-191 signer recovered here, against Countersign's pinned agent. The memo is relayed unchanged by /api/memo only because Countersign's API sends no CORS header; an altered relay would fail this check.
